# Contributing

This is brand work for Skin Theory, published as a record of the build rather than as a template.
**It carries no licence**, so it is not open for reuse and code contributions are not being taken.

That said, two things are genuinely welcome.

## Report a problem

If you find something broken — a page that fails to render, a checkout step that misbehaves, a
broken link, an accessibility problem — please open an issue. Say what you did, what you expected,
and what happened instead, plus your browser.

## Report a security issue

Do **not** open a public issue for anything security related. Open a
[security advisory](../../security/advisories/new) instead. See [SECURITY.md](SECURITY.md).

## Please do not

- **Reuse the brand assets or the product copy.** The box artwork in `brand/`, the extracted brand
  rules and the product text belong to Skin Theory. They are in this repo because the site is built
  from them, not because they are free to take.
- **Open a pull request that changes the design.** The look is derived from the printed packaging
  on purpose. Changes to it are a brand decision, not a code review one.

Referencing the technical approach is fine. Ask before reusing anything that carries the brand.
